# Ameba-D SDK 선별 복사 목록
#
# sync_sdk.sh 가 이 파일을 읽어 sdk/ameba-rtos-d/ → src/lib/Realtek/ 로 복사한다.
# 복사 결과는 git 에 커밋되고, 빌드는 src/lib/Realtek/ 만 참조한다.
# 즉 일반 clone 후에는 서브모듈 없이 그대로 빌드된다.
#
# 형식:  <SDK 기준 상대경로>  ->  <src/lib/Realtek/ 기준 상대경로>
#   경로가 / 로 끝나면 디렉토리 전체를 복사한다.
#   # 로 시작하는 줄과 빈 줄은 무시한다.
#
# 방침: STM32 프로젝트가 STM32H5xx_HAL_Driver/Src/*.c 를 전부 넣고 --gc-sections 로
#       떨어내던 것과 동일하게, .c 도 디렉토리 단위로 넉넉히 가져온다.
#       빌드에서 빼야 하는 파일은 CMakeLists.txt 의 EXCLUDE_PATHS 로 처리한다.
#       (전부 합쳐 약 3MB — 의존 관계를 손으로 추적하는 비용이 더 크다)

# ══════════════════════════════════════════════════════════════════════════
#  런타임 소스 — 디렉토리 전체
# ══════════════════════════════════════════════════════════════════════════
# ram_hp/   : KM4 전용 (14 파일). SDK make/target/fwlib/Makefile 이 전부 빌드한다.
# ram_common: 양 코어 공용 (20 파일). KM4 빌드는 18 개만 쓴다
#             (rtl8721d_efuse.c, rtl8721d_qdec.c 제외 — ROM 에 있거나 미사용).
# usrcfg/   : 보드/사용자 설정. KM4 빌드가 쓰는 것은 4 개뿐이고
#             나머지는 KM0/부트로더 몫이다. 아래 "빌드 제외" 참고.
#
# ★ ram_lp/ (KM0 전용) 는 복사하지 않는다. KM4 이미지에 들어가면 안 된다.
component/soc/realtek/amebad/fwlib/ram_hp/             -> fwlib/ram_hp/
component/soc/realtek/amebad/fwlib/ram_common/         -> fwlib/ram_common/
component/soc/realtek/amebad/fwlib/usrcfg/             -> fwlib/usrcfg/

#      → QFN88 EVB 변종. rtl8721dlp_pinmapcfg.c 와 같은 심볼을 정의하므로
#        둘을 함께 빌드하면 중복 정의로 링크가 깨진다.
#
#  KM4 가 실제로 쓰는 usrcfg 4 개 (SDK make/target/fwlib/Makefile 기준):
#      rtl8721dlp_intfcfg.c  rtl8721dhp_intfcfg.c  rtl8721d_ipccfg.c  rtl8721d_wificfg.c
#      ※ rtl8721d_wificfg.c 는 WiFi 를 안 써도 필요하다 —
#        app_start() 가 rtk_wifi_config.km4_cache_enable 을 참조한다.
